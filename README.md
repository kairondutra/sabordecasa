# Sabor de Casa

Sistema web para gestão e venda de marmitas.

##  Sobre o Projeto

O **Sabor de Casa** é uma solução desenvolvida para facilitar a venda de marmitas de forma online, permitindo que o cliente visualize o cardápio, monte seu pedido e finalize a compra de maneira rápida e prática.

O projeto também conta com um painel para o lojista gerenciar os produtos e acompanhar os pedidos.

##  Objetivo

Desenvolver um MVP (Produto Mínimo Viável) focado em melhorar a experiência de compra de marmitas e auxiliar pequenos empreendedores do ramo alimentício, contribuindo com a ODS 8 – Trabalho Decente e Crescimento Econômico.

##  Funcionalidades do MVP

- Visualização do cardápio de marmitas
- Adicionar itens ao carrinho
- Finalização de pedido
- Painel administrativo básico (cadastro de produtos e visualização de pedidos)

##  Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

##  Como executar o projeto

1. Clone o repositório:
```bash
git clone https://github.com/kairondutra/sabordecasa.git
```

2. Abra o arquivo index.html no navegador.
